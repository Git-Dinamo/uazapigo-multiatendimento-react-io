# Handoff

Estado: app/ é um site estático (Vite+React+TS) que recria o inbox multiatendimento do Bubble falando direto com a UAZAPI (header token; /chat/find, /message/find, SSE /sse; editLead para atribuir/abrir-fechar/pausar robô; /chat/labels; /quickreply/showall; /send/text e /send/media com mp3 gravado). Camada de provedor em src/provider (uazapi.ts; demo.ts responde em memória quando a URL tem ?demo; ?c=<numero> abre conversa). rebuild_check passa (96%). Não testado contra uma instância UAZAPI real: formatos de resposta (ex.: id usado no editLead, unidade de lead_disableChatBotUntil em segundos, /message/download com return_link) são estimativas a partir do plugin. Próximo: testar com instância real; opcional adaptador para a API Dinamo (outros provedores). Armadilha: o token da instância fica no navegador, como no Bubble.
